This repo contains a digital twin to monitor the level of air pollutants at chosen cities: Chicago, Sacramento, Bangalore and New Delhi.

Please find the demonstration of this digital twin [here](https://www.youtube.com/watch?v=H5qFuUWYyNY)

This app is about how digital twins could be used to monitor the pollutant levels in a city. The digital twin has three pages

1. Data Coverage Summary   
This page gives information on the daily coverage at each location of the selected city.

2. Sensor Locations and Raw data   
This page helps visualize the sensor locations in the selected city on the left panel. The right panel helps in visualizing the pollutant levels with time at selected location at the top. One could discern how the pollutant level at the selected location compares with other locations in the city.

3. Forecasting of Average Values   
This pages is about forecasting the average value of the pollutant at a given location. The forecast is done a Prophet.
